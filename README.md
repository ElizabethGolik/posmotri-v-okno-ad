# «Посмотри в окно»

[![Tests](https://github.com/ElizabethGolik/posmotri-v-okno-ad/actions/workflows/tests.yml/badge.svg)](https://github.com/ElizabethGolik/posmotri-v-okno-ad/actions/workflows/tests.yml)

Учебное приложение с видеозаписями разных городов. Интерфейс позволяет искать ролики по городу и времени суток, менять основное видео и подгружать новые карточки.

## Технологии

- семантический HTML;
- CSS Flexbox;
- кастомные элементы формы;
- состояния наведения, фокуса и выбора;
- JavaScript для загрузки и фильтрации данных.
